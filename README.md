# AthenAI Technologies

אתר הנחיתה של AthenAI Technologies: הטמעת AI, סוכני AI והרצאות לחברות ומשרדים. האתר דו־לשוני (עברית ואנגלית).

אתר סטטי בקובץ `index.html` אחד, בלי build ובלי תלויות.

## פריסה ב־Vercel

ייבוא הריפו ב־Vercel עם ההגדרות הבאות:

- Framework Preset: Other
- Build Command: ריק
- Output Directory: `.`

כל push ל־`main` עולה לפרודקשן אוטומטית.

קישור ישיר לגרסה האנגלית: `/?lang=en`
